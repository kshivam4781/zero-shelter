# QA Reports

Reports are short, dated records of a completed inspection. They do not redefine cases or quality gates. Copy [TEMPLATE.md](TEMPLATE.md) to `YYYY-MM-DD.md` only after an inspection has started.

## Report rules

- State the candidate version or commit, scope, and execution mode.
- Report verified outcomes only; use `Not run` for unexecuted work.
- Name P0/P1 blockers and untested scope explicitly.
- Link case IDs and automated evidence rather than pasting raw scanner output.
- Use only synthetic or sanitized detail.
